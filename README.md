# Conquest of AzerothCore Launcher — Releases

Download the latest launcher installer from **[Releases](../../releases/latest)** (`CoaLauncher-win-Setup.exe`).

This repository holds only published launcher builds. Installed launchers check it for updates
automatically (every 15 minutes and at start) and update themselves. Each release contains the
installer, the update packages and the update feed (`releases.win.json`), which is signed with the
launcher's update key; launchers refuse a feed with a missing or wrong signature once signing is
enabled.

The source code is private.
